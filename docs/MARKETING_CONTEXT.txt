2. WHAT UNEMPLOYED.SK IS
================================================================================

ONE-LINER
  "AI-powered career platform for Gen Z in Slovakia."

ELEVATOR PITCH (30 seconds)
  unemployed.sk is a career platform built for students and graduates in Slovakia.
  Students discover jobs by swiping through listings — like Tinder for jobs — with
  AI-powered matching that scores how well each position fits their profile. Upload
  your CV, get an AI-generated professional profile, and find your match. Employers
  get a professional dashboard with AI-scored candidates, analytics, and smart
  recruitment tools. We handle part-time gigs, internships, and full-time roles.

EXPANDED DESCRIPTION
  unemployed.sk connects Slovak students and graduates with verified employers
  through a mobile-first, AI-driven job discovery experience. The platform uses
  OpenAI GPT-4o-mini to parse CVs, generate bilingual professional profiles, and
  compute multi-dimensional match scores (0–100) across skills, education,
  experience, location, and languages. Students interact with job cards through
  a Tinder-style swipe interface on mobile, while employers manage listings,
  evaluate ranked candidates, and track recruitment analytics through a
  professional desktop dashboard. The entire platform supports both Slovak and
  English, with AI content generated bilingually.

4. PLATFORM FEATURES — STUDENT SIDE
================================================================================

FOR YOU FEED (Tinder-style job swiping)

  • AI extracts: skills, education, experience, languages
  • Generates: bilingual headline, executive summary, strengths, development areas,
    suggested roles, portfolio introduction
  • Fallback: Rule-based NLP when AI limits reached
  • Profile strength indicator shows completion percentage

ONBOARDING FLOW
  • CV upload → AI parse → profile review → skill selection → manual fallback
  • Zero-friction: designed to get students matched ASAP

APPLICATION TRACKING
  • Track all applied jobs in one place
  • Interview scheduling: accept, decline, or counter-offer with custom dates
  • Real-time notifications for status changes

COMPANY PROFILES
  • Instagram-style company page with job listings, stats, and location map
  • Browse company culture before applying

SAVED JOBS
  • Bookmark listings to review later

6. AI & TECHNOLOGY DIFFERENTIATORS
================================================================================

AI MATCHING ENGINE
  • Powered by OpenAI GPT-4o-mini
  • 5-dimension scoring: Skills, Education, Experience, Location, Languages
  • Synonym-aware skill matching with transferable skill families
  • Education level + field matching (exact, related, partial)
  • Experience years + level compatibility
  • City/region overlap with work model consideration
  • Required + preferred language matching
  • Pre-computed scores cached for instant loading
  • Recalculated on any profile or criteria change

CV PARSING PIPELINE
  1. Upload PDF or DOCX
  2. Text extraction via pdf-parse / mammoth
  3. GPT-4o-mini structured extraction (with NLP fallback)
  4. Bilingual profile generation (Slovak + English)
  5. Match score computation against all active jobs
  6. Score caching for performance

BILINGUAL AI CONTENT
  • All AI-generated content produces both Slovak and English versions
  • Headlines, summaries, strengths, development areas, role suggestions
  • Rendered dynamically based on user's language preference

TECH STACK (for technical marketing / press)
  • Frontend: React 18 + Vite (4 independent apps)
  • Animations: Framer Motion (spring physics, layout transitions)
  • Maps: Leaflet + React-Leaflet (CartoDB dark tiles)
  • Backend: Node.js + Express
  • Database: Supabase (PostgreSQL + Row Level Security)
  • AI/ML: OpenAI GPT-4o-mini
  • Hosting: Netlify (static) + VPS (Express server)
  • Localization: Custom bilingual system (SK/EN)
