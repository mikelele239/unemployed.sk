# Submissions Model (`submissions` table)

> [!WARNING]
> This table stores all landing page user signups (emails and phones) representing the core customer acquisition leads pipeline. Do not drop, modify, or truncate this table without extreme care.

## Table Schema

| Column | Data Type | Constraints / Default | Description |
|---|---|---|---|
| `id` | `BIGINT` | `PRIMARY KEY`, `GENERATED BY DEFAULT AS IDENTITY` | Unique submission tracking ID. |
| `email` | `TEXT` | `UNIQUE NOT NULL` | Target signup email address. |
| `phone_prefix`| `TEXT` | | International calling code prefix (e.g. `+421`). |
| `phone` | `TEXT` | | Mobile/fixed line telephone number. |
| `user_type` | `TEXT` | `NOT NULL` | Lead category (e.g. `student` or `employer`). |
| `consented` | `BOOLEAN` | `DEFAULT TRUE` | Confirming user approved privacy terms/GDPR. |
| `marketing_consent` | `BOOLEAN` | `DEFAULT FALSE` | Confirming user approved newsletters/marketing calls. |
| `ip_hash` | `TEXT` | | MD5/SHA hash of user IP address for rate-limiting. |
| `company_name`| `TEXT` | | Associated company name (for employer signups). |
| `created_at` | `TIMESTAMPTZ`| `DEFAULT NOW()` | Lead signup timestamp. |

## API Endpoints
- **`POST /api/submit`**: Landing page submission controller routing to this table. Includes duplicate checking and IP rate limiting.

## Row-Level Security (RLS) Policies
- **`Allow public insert submissions`**: Permits insertions (`INSERT`) from any client.
- **`Allow service select submissions`**: Enables admin tools and controllers to query and cross-check records.
