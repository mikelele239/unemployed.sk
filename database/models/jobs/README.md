# Jobs Model (`jobs`, `job_views`, `job_likes` tables)

The `jobs` table contains all job postings on the platform. It is accompanied by `job_views` and `job_likes` tables that track candidate engagement.

## Table Schemas

### 1. Jobs Table (`jobs`)

| Column | Data Type | Constraints / Default | Description |
|---|---|---|---|
| `id` | `BIGINT` | `PRIMARY KEY`, `GENERATED BY DEFAULT AS IDENTITY` | Unique listing ID. |
| `employer_id` | `UUID` | `REFERENCES public.employers(id) ON DELETE SET NULL` | Reference to posting company. |
| `title` | `TEXT` | `NOT NULL` | Job title. |
| `company` | `TEXT` | `NOT NULL` | Legacy denormalized company name. |
| `logo` | `TEXT` | | Icon or company logo. |
| `color` | `TEXT` | `DEFAULT '#FF5C00'` | Decorative hex background color. |
| `location` | `TEXT` | | Physical work location. |
| `lat` | `DOUBLE PRECISION` | | Latitude coordinate. |
| `lng` | `DOUBLE PRECISION` | | Longitude coordinate. |
| `rate` | `TEXT` | | Numeric pay rate value (e.g. `7.50`). |
| `rate_unit` | `TEXT` | `DEFAULT '/hod'` | Unit of pay (e.g. `/hod`, `/mesiac`). |
| `hours` | `TEXT` | | Hours per week text. |
| `type` | `TEXT` | | Job type (e.g. `Part-time`, `Internship`). |
| `duration` | `TEXT` | | Duration text. |
| `start_date` | `TEXT` | | Expected start date. |
| `work_model` | `TEXT` | | Remote, Hybrid, or On-site. |
| `tags` | `JSONB` | `DEFAULT '[]'::jsonb` | Tag filters. |
| `schedule` | `TEXT` | | Shift description. |
| `description` | `TEXT` | | Listing description. |
| `requirements` | `TEXT` | | Job requirement text details. |
| `total_views` | `INTEGER` | `DEFAULT 0` | Auto-incremented view count. |
| `total_likes` | `INTEGER` | `DEFAULT 0` | Auto-incremented like count. |
| `created_at` | `TIMESTAMPTZ` | `DEFAULT NOW()` | Record creation timestamp. |

### 2. Job Views Table (`job_views`)
Tracks impressions when candidate cards are swiped or clicked.
- `id` (UUID): Primary key.
- `job_id` (BIGINT): Reference to `jobs.id`.
- `viewer_id` (UUID): Optional reference to `auth.users(id)`.
- `viewed_at` (TIMESTAMPTZ): Created timestamp.

### 3. Job Likes Table (`job_likes`)
Tracks student bookmarking.
- `id` (UUID): Primary key.
- `job_id` (BIGINT): Reference to `jobs.id`.
- `user_id` (UUID): Reference to `auth.users(id)`.
- `created_at` (TIMESTAMPTZ): Created timestamp.

## Triggers & Functions
- **`trg_increment_job_views`**: Runs after insert on `job_views` to increment `jobs.total_views`.
- **`trg_increment_job_likes`**: Runs after insert on `job_likes` to increment `jobs.total_likes`.
- **`trg_decrement_job_likes`**: Runs after delete on `job_likes` to decrement `jobs.total_likes`.

## API Endpoints
- **`GET /api/jobs`**: Fetch all active jobs.
- **`POST /api/jobs`**: Insert new listing (Employer auth required).
- **`PATCH /api/employer/jobs/:id`**: Update listing.
- **`DELETE /api/jobs/:id`**: Remove listing.
- **`POST /api/jobs/:id/view`**: Register view event.

## Row-Level Security (RLS) Policies
- `jobs`: Publicly readable (`SELECT`) by all users. Insert/Updates route via proxy.
- `job_views`: Inserts permitted by any authenticated users. Selected only by posting employers.
- `job_likes`: Authenticated users manage own records. Employers read counts for their listings.
